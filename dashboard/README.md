# UBON FLOW — Logistics Dashboard

Dashboard ภาษาไทย ใช้ข้อมูลจำลองจากชุด Ubon Logistics ที่สร้างไว้โดยตรง ไม่ทำขั้น Data Warehouse หรือ Data Mining ตามขอบเขตที่ผู้ใช้เลือก

## เปิดใช้งาน

เปิด terminal ในโฟลเดอร์นี้แล้วรัน `python -m http.server 4173 --bind 127.0.0.1` จากนั้นเปิด `http://127.0.0.1:4173/` ต้องเปิดผ่าน HTTP เพื่อโหลดไฟล์ข้อมูล

## ส่วนที่ใช้งานได้

- ภาพรวม KPI แผนที่ประเทศไทย เส้นปะเคลื่อนไหว และตารางสี OTD แยกจังหวัด/เดือน
- กดเส้นทางหรือจุดปลายทาง เปิดผลงานเส้นทางและรายการส่งล่าสุด
- รายการส่ง 12,000 รายการ ค้นหาตามรหัส ลูกค้า จังหวัด กรองบริการและสถานะ แบ่งหน้า และดูไทม์ไลน์
- จากรายการส่งเปิดเที่ยวรถ แล้วดูรถและคนขับที่ได้รับมอบหมายได้
- รถ 46 คัน พร้อมความจุ ระยะทางเที่ยวที่ปิดแล้ว ต้นทุน/กม. และอัตราจองใช้งาน
- คนขับจำลอง 70 คน พร้อมรถประจำ เที่ยวที่ร่วมขับ และคะแนนประวัติสมมติ
- เปรียบเทียบสองเส้นทาง ตามเดือนและบริการที่เลือก
- วิเคราะห์ต้นทุน 6 หมวดจากการจัดสรรเที่ยวรถ พร้อมทดลองราคาน้ำมันและประสิทธิภาพ กม./ลิตร
- ส่งออก CSV ตามตัวกรอง มี UTF-8 BOM เพื่อเปิดชื่อไทยใน Excel
- เมนูข้อมูลอ้างอิง มีสูตร KPI สมมติฐาน และลิงก์เอกสารต้นทาง
- รองรับแป้นพิมพ์ การหยุดเคลื่อนไหว และหน้าจอมือถือ

## นิยามและข้อจำกัด

ข้อมูลทุกเหตุการณ์เป็นข้อมูลจำลอง ณ 30 กันยายน 2568 เวลา 23:59:59 ประเทศไทย ข้อมูลที่ยังไม่เกิดขึ้น ณ วันนั้นแสดงเป็นค่าว่าง ไม่แสดงเป็นศูนย์จริง

OTD = ส่งสำเร็จไม่เกินกำหนด / ส่งสำเร็จทั้งหมด งานค้างและงานยกเลิกไม่อยู่ในตัวหาร

ภาพรวม รายการส่ง เส้นทาง และต้นทุนกรองตามวันรับงาน ส่วนรถ/คนขับกรองตามวันออกเดินทางตามแผนของเที่ยว ไม่กรองบริการบนหน้ารถและคนขับ เพราะเที่ยวหนึ่งอาจบรรทุกหลายบริการ

ต้นทุนบนหน้าภาพรวม/วิเคราะห์แบ่งจากเที่ยวที่ปิดแล้วไปยังรายการส่งตามน้ำหนัก รวมเที่ยวกลับและนำจ่ายซ้ำ ค่าน้ำมันอยู่ในยอดรวมแล้ว หากบางช่วงยังไม่ปิด ยอดรายการส่งยังเป็นต้นทุนบางส่วน

โครงสร้างต้นทุนตามตัวกรองแบ่งแต่ละหมวดด้วยสัดส่วนต้นทุนที่จัดสรรจากเที่ยวนั้น ผลรวมรายการย่อยอาจต่างจากยอดรวมไม่กี่สตางค์เนื่องจากการปัดเศษหน้าจอ

การใช้รถ = ชั่วโมงจองรถรวมพักระหว่างเที่ยว/ขากลับ / ชั่วโมงพร้อมใช้หลังหักซ่อม ไม่ใช่ชั่วโมงติดเครื่อง หากกรองจังหวัด ตัวเลขอัตราจองใช้งานยังเป็นการใช้รถคันนั้นตลอดเดือนที่เลือก

ทดลองต้นทุน: น้ำมันใหม่ = น้ำมันฐาน × (1 + %เปลี่ยนราคา) / (1 + %เพิ่มประสิทธิภาพ กม./ลิตร) จากนั้นบวกต้นทุนหมวดอื่นคงเดิม เป็นสมมติฐาน ไม่มีโมเดลทำนาย และไม่ใช่ราคาน้ำมันปัจจุบัน

จุดใจกลางเมืองสมมติแทนศูนย์จริง เส้นปะเป็นเส้นเชื่อมศูนย์ ไม่ใช่ถนนหรือ GPS การเคลื่อนไหวบนแผนที่เป็นการสื่อสารทิศทางเครือข่าย

## แหล่งแผนที่และตัวอักษร

ขอบเขตประเทศจาก Natural Earth 1:50m (`ne_50m_admin_0_countries.geojson`) จาก https://github.com/nvkelso/natural-earth-vector — ข้อมูล public domain ตาม https://www.naturalearthdata.com/about/terms-of-use/ ดึงวันที่ 2 ตุลาคม 2569

ระยะถนนใช้ OSRM/OpenStreetMap ตามแหล่งอ้างอิงของข้อมูลเดิม ไม่ใช้รูปทรงแผนที่คำนวณระยะทาง https://www.openstreetmap.org/copyright

โหลดตัวอักษร IBM Plex Sans Thai และ Manrope ผ่าน Google Fonts มีระบบสำรองตัวอักษรหากเครือข่ายไม่พร้อม

## โครงสร้าง

- `index.html`, `styles.css`, `app.js`: หน้าเว็บและการโต้ตอบ ไม่มีขั้นติดตั้ง dependency
- `assets/data.json`: ตารางหลักจาก CSV บีบรูปแบบคอลัมน์/แถวเพื่อประหยัดขนาด
- `assets/details.json`: เหตุการณ์และช่วงขนส่ง โหลดเมื่อเปิดไทม์ไลน์หรือต้นทุน
- `assets/boundaries.json`: ขอบเขตไทยและประเทศข้างเคียง
- `prepare_data.py`: สร้าง JSON ใหม่จาก CSV ต้นฉบับใน `../data` เก็บไฟล์ขอบเขตเดิมได้
- `vercel.json`: การตั้งค่าเว็บแบบ static

## ขึ้น Vercel

นำโฟลเดอร์ `dashboard` นี้เป็น Root Directory ของโปรเจกต์ เลือก Framework Preset: Other ไม่ต้องมี Build Command และใช้รากโฟลเดอร์นี้เป็น Output Directory หากนำ repo ทั้งชุดขึ้น ให้เลือก Root Directory เป็น `logistics-dss/dashboard`

ไฟล์ข้อมูลไม่มีข้อมูลบุคคลจริง เว็บไม่มีระบบล็อกอิน บันทึกแก้ไข หรือ GPS สด ข้อมูลและผลคำนวณทำงานในเบราว์เซอร์
